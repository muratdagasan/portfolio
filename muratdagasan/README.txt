YAYINLAMA (ücretsiz, GitHub Pages)
1. github.com'da "muratdagasan" kullanıcı adıyla hesap aç.
2. "muratdagasan.github.io" adında PUBLIC bir depo oluştur.
3. Bu klasördeki tüm dosyaları (index.html, admin.html, data.json, photos/) depoya yükle.
4. Depo > Settings > Pages > Branch: main / root > Save.
   Adres: https://muratdagasan.github.io
5. Yönetici paneli: https://muratdagasan.github.io/admin.html
   Token: GitHub > Settings > Developer settings > Fine-grained tokens
   > sadece bu depo, Contents: Read and write.

DAHA SONRA TAŞIMA
Site düz HTML'dir. Depodaki dosyaları Netlify, Cloudflare Pages veya
ücretli herhangi bir hosting'e kopyalaman yeterli. Özel alan adı
(muratdagasan.com) için hosting panelinden alan adını bağlaman yeterli.
